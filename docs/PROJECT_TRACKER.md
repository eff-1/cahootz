Per the Hardening Pass directive:
- Milestones **M4 (`T-013`–`T-015`), M5 (`T-016`–`T-018`), and M6 (`T-019`–`T-022`)** are held at **`Built, partially verified`** until external CI tools (`OWASP ZAP` baseline container, `k6` 5-minute 100-VU run on GitHub Actions) and counsel/production infrastructure checks complete.
- All local persistence writes execute as immediate per-operation SQLite transactions (`BEGIN IMMEDIATE; COMMIT;`). A dedicated crash test abruptly kills the server process with `SIGKILL` mid-session immediately following an acknowledged write, proving that state survives restart with zero data loss.
- `/metrics` and `/api/v1/observability/metrics` are protected with a Bearer token (`METRICS_BEARER_TOKEN`), returning `401 Unauthorized` for unauthenticated requests.
- Real Playwright browser numbers are captured directly from headless Chromium execution at `375x667` with Slow 3G throttling.
- A real email adapter interface with Resend and SMTP implementations is integrated, with automated smoke test verifying 6-digit OTP delivery and confirmation.
- Off-site encrypted backup to S3-compatible storage using AES-256-GCM is implemented and verified with a point-in-time restore drill into a clean database.
- Reverse proxy configs for Caddy and Nginx are added to `infra/`, and HTTPS/CSP/cookie security is verified.
- The scale exit plan to PostgreSQL + Redis is documented in `docs/scale-exit-plan.md` with explicit quantitative triggers.
