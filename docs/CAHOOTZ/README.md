# CAHOOTZ — Documentation Hub

**Learn together. Go further.**

Cahootz is a proposed social learning and student productivity ecosystem for university students, starting in Nigeria (web-first). Its signature feature is **Study Together**: students find a partner from their own course, agree a timed session and hold each other fairly accountable. Other pillars: academic communities, an AI study assistant, messaging/video and an XP and virtual-coin system.
